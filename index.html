Pilpel Lab assistant

One internal assistant for the lab's day-to-day operations. It handles scheduling and email today, and is built as a set of tools so it can take on more of the lab's routine work over time, without turning into a pile of one-off scripts.

Scheduling

Keeps the lab's group-meeting calendar in sync with the lab schedule sheet, including speaker names and time overrides.

Email

Sends and triages lab notifications from the lab account, and reads the replies that need a follow-up.

Built to grow

Each capability is a separate tool behind the same assistant. New lab workflows are added as tools, not as new integrations bolted on.

How it is built

One assistant, many tools

The assistant is a single agent with a growing set of tools. Today those tools cover the lab calendar and the lab mailbox. Future tools are expected to cover other routine operations the lab chooses to delegate, such as compute jobs, meeting notes, reminders, and data lookups.

Least privilege

The assistant acts only on the single lab account that granted it access, and only within the scopes that account approved. It does not have standing access to anything the lab has not explicitly granted, and it never reaches into other people's accounts.

Explicit consent for new access

Adding a capability that needs a new Google permission means a new consent step by the lab account. Access is never expanded silently. The privacy policy is updated before any new category of Google data is requested.

This is a private, single-account tool for one lab. It has no public sign-up and is not offered as a service to anyone else.
